# Gulf Mobiles Android App

A simple offline sales tracker for Gulf Mobiles.

## Included
- Gulf Mobiles branded dashboard
- Sale / Expense / Profit columns
- Automatic Profit = Sale - Expense
- Total Sale, Total Expense and Total Profit
- Sales history
- Long-press an entry to delete it
- Local SQLite storage; no internet is required for the sales data

## Build
Open this folder in Android Studio and build `app` > `assembleDebug`.
The generated APK will be under `app/build/outputs/apk/debug/`.
- Basic Job Sheets: customer, phone, device/model, complaint, status and service amount
